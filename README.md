### About me

I'm a software developer with **4 years of hands-on experience** building applications across Android, iOS, Windows, and macOS.

- **Mobile:** Flutter and Dart, with native Android (Kotlin) and iOS (Swift) integration.
- **Desktop:** Electron, React, TypeScript, and native C++ integrations.
- **Real-time communication:** SIP/VoIP, PJSIP, WebSocket, and push notifications.
- **Backend & data:** Node.js, Express.js, REST APIs, SQL databases, and local persistence.

I enjoy solving challenges where cross-platform frameworks meet native systems—from application architecture to shipping production releases.
